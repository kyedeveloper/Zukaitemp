Kebijakan Privasi

ZukaiTemp · diperbarui 6 Oktober 2026 · zukaitemp.vercel.app

Summary: ZukaiTemp only reads your Google name, email and profile photo if you choose to sign in, and your YouTube playlists (read-only) only if you separately tap "Hubungkan YouTube". YouTube data is fetched by your browser and stored only on your device. We do not sell data or use it for ads. Requests you send to the owner are stored in our database until deleted.

1. Siapa kami

ZukaiTemp (zukaitemp.vercel.app) adalah aplikasi web berisi email sementara, pemutar musik, downloader, dan tools, yang dikelola oleh pengembang perorangan. Kontak: GANTI-EMAIL-KAMU@gmail.com, atau lewat menu Request di aplikasi.

2. Data yang kami proses

Akun Google (hanya jika kamu masuk). Nama, alamat email, dan foto profil. Data ini disimpan di browser perangkatmu (localStorage). Token akses Google berlaku sekitar 1 jam. Server hanya menerima token itu untuk memverifikasi identitasmu ke Google (fitur owner dan pelabelan request); token tidak disimpan di database kami.

Data YouTube (hanya jika kamu menekan "Hubungkan YouTube"). Kami meminta izin baca saja (youtube.readonly) untuk melihat daftar playlist dan video yang kamu sukai. Data ini diambil langsung oleh browsermu dari YouTube, tidak dikirim ke server kami, dan hanya judul, nama kanal, durasi, dan gambar mini lagu yang kamu pilih untuk diimpor yang disimpan di perangkatmu sebagai playlist. Kami tidak mengubah atau menghapus apa pun di akun YouTube-mu.

Request ke owner. Kategori, isi pesan, kontak (opsional), nama tampilan, ID perangkat acak, email Google (bila kamu masuk), dan waktu kirim. Disimpan di database (Upstash Redis) dan bisa dibaca owner.

Alamat IP. Dipakai sementara untuk membatasi pengiriman berlebihan (penghitung otomatis hilang dalam 1 jam). Penyedia hosting (Vercel) dapat mencatat log server standar.

Data di perangkatmu. Favorit, playlist, pengaturan tampilan, log aplikasi, dan cache tersimpan di browser dan tidak dikirim ke server kami.

3. Untuk apa data dipakai

  • Menampilkan profilmu dan mengaktifkan fitur akun.
  • Mengimpor playlist YouTube yang kamu pilih ke tab Musik.
  • Menerima dan menjawab request, serta mengenali owner untuk mengirim pengumuman.
  • Mencegah penyalahgunaan (batas kirim request).

Kami tidak menjual data, tidak menampilkan iklan, dan tidak memakai data Google untuk periklanan atau melatih model AI.

4. Layanan pihak ketiga

Beberapa fitur memakai layanan luar, dan permintaan yang relevan (misalnya kata pencarian lagu) dikirim ke mereka: Google/YouTube (login, pemutar, dan Data API), Audius, Deezer, Apple (pencarian musik), Internet Archive, LRCLIB (lirik), penyedia email sementara, Vercel (hosting), dan Upstash (database). Masing-masing punya kebijakan privasinya sendiri. Pesan yang masuk ke alamat email sementara diproses oleh penyedia email sementara tersebut, jadi jangan dipakai untuk akun yang penting.

5. Kepatuhan Google API

Penggunaan dan pengalihan informasi yang diterima dari Google API oleh ZukaiTemp mematuhi Kebijakan Data Pengguna Layanan Google API, termasuk persyaratan Penggunaan Terbatas (Limited Use). Dengan memakai fitur YouTube, kamu juga terikat Ketentuan Layanan YouTube dan Kebijakan Privasi Google.

6. Penyimpanan dan penghapusan

  • Keluar dari akun (Menu → Akun → Keluar) menghapus profil dan token dari perangkat serta mencabut token di Google.
  • Menu → Penyimpanan & cache → Hapus semua data membersihkan seluruh data di perangkat.
  • Cabut izin kapan saja di myaccount.google.com/permissions.
  • Request dan pengumuman tersimpan di database sampai dihapus. Minta penghapusan request-mu lewat kontak di atas dan sertakan ID perangkat dari Menu.

7. Anak-anak

Layanan ini tidak ditujukan untuk anak di bawah 13 tahun.
